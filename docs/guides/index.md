# Consumer Guides

> Type: Guide index. These documents show supported usage paths without
> duplicating the complete API contract.

Use these guides for task-oriented examples:

- [Getting Started](./getting-started.md) explains the shared `pfs` instance,
  custom working directories, and path resolution.
- [File Workflows](./file-workflows.md) combines directory creation, file
  operations, copying, renaming, and cleanup.
- [Sync Mode And Errors](./sync-mode-and-errors.md) compares asynchronous and
  synchronous calls and explains their error behavior.

For individual method signatures and options, use the
[API reference](../../readme.md#class-poweredfilesystem). The exported
TypeScript declarations in
[`src/powered-file-system.ts`](../../src/powered-file-system.ts) are the source
of truth for the public contract.
